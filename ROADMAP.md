# Roadmap / Плани

## 1.5 — Queue and library tools / Черга й інструменти бібліотеки

### Play next / Грати наступним

**English.** “Play next” in a track's menu (and on the phone remote): the track plays right after the current one without reordering the playlist. Several tracks line up in a small queue.

**Українська.** «Грати наступним» у меню треку (і на пульті з телефона): трек заграє одразу після поточного, порядок плейлиста не змінюється. Кілька таких треків стають у невелику чергу.

### Copy to a USB stick / Скопіювати на флешку

**English.** Copy a playlist (for example, Favorites) to a folder or a USB stick with numbered file names, so a car stereo or a speaker plays them in the same order. Shows the total size first; never overwrites files without asking.

**Українська.** Скопіювати плейлист (наприклад, «Улюблені») у теку чи на флешку з нумерацією в назвах файлів, щоб магнітола чи колонка грали їх у тому самому порядку. Спершу показує загальний розмір; не перезаписує файли без запиту.

### Find duplicates / Знайти дублікати

**English.** Finds the same track stored in several folders (by artist, title and length, and by identical files) and shows them side by side; you choose which copy to keep. Removal works like “Remove non-favorites”: from the list only by default, or to the Trash — never permanently.

**Українська.** Знаходить той самий трек, що лежить у кількох теках (за виконавцем, назвою й тривалістю, а також однакові файли), і показує їх поруч; ви обираєте, яку копію залишити. Прибирання — як у «Прибрати неулюблені»: за замовчуванням лише зі списку, або в Кошик — ніколи назавжди.

### Find missing covers online / Знайти обкладинки в інтернеті

**English.** For albums with no cover in the files or the folder, Plativka can look the cover up online: MusicBrainz + Cover Art Archive first (free, no keys), iTunes Search as a fallback. Off by default — it sends artist and album names to these services, so you turn it on yourself. Smart matching: ignores “(Remastered)”, “[Deluxe]”, “feat.”, case and quotes, finds Cyrillic and Latin spellings (Океан Ельзи / Okean Elzy), accepts only a confident match (artist, album, track count or year) — no cover is better than a wrong one. When unsure: right-click → **Find cover…** shows 4–6 options to choose from. One lookup per album, cached (works offline afterwards); optionally saves the cover as `cover.jpg` next to the album.

**Українська.** Для альбомів без обкладинки у файлах чи теці Платівка може знайти її в інтернеті: спершу MusicBrainz + Cover Art Archive (безплатно, без ключів), запасне — iTunes Search. Вимкнено за замовчуванням — надсилає назви виконавців і альбомів цим сервісам, тож вмикаєте самі. Розумне порівняння: ігнорує «(Remastered)», «[Deluxe]», «feat.», регістр і лапки, знаходить кириличне й латинське написання (Океан Ельзи / Okean Elzy), приймає лише впевнений збіг (виконавець, альбом, кількість треків чи рік) — краще без обкладинки, ніж чужа. Якщо не впевнена: правий клік → **Знайти обкладинку…** показує 4–6 варіантів на вибір. Один запит на альбом, з кешем (далі працює без інтернету); за бажанням зберігає обкладинку як `cover.jpg` поруч з альбомом.
