# Roadmap / Плани

Version 1.8 is out — see the [changelog](CHANGELOG.md). / Версія 1.8 вийшла — див. [історію змін](CHANGELOG.md).

## Next version / Наступна версія

- **A long recording as tracks** — done in `main`: paste a track list with times, Plativka writes a `.cue` ([guide](docs/en/desktop.md#a-long-recording-as-tracks)).
  **Довгий запис — окремими треками** — уже в `main`: вставляєте список із часом, Платівка пише `.cue` ([інструкція](docs/uk/desktop.md#довгий-запис--окремими-треками)).
- **Single files to the playlist** — done in `main`: **+ Add → Files…**, `Ctrl+Shift+O`.
  **Окремі файли в список** — уже в `main`: **+ Додати → Файли…**, `Ctrl+Shift+O`.

Ideas are welcome — open an issue on GitHub. / Ідеї вітаються — напишіть на GitHub.

## Not planned / Не плануємо

- Internet radio: Plativka stays a player for the music on your disk. / Інтернет-радіо: Платівка лишається плеєром для музики на диску.

## Later / Пізніше
