# Встановлення Платівки на Linux

[English](../en/install-linux.md) · [До README](../../README.uk.md)

Платівка встановлюється одним скриптом, який працює на **Debian, Ubuntu, Linux Mint, Pop!_OS, Fedora, Arch, Manjaro, EndeavourOS і openSUSE**. Він ставить потрібні системні пакети, кладе плеєр у вашу домашню теку й додає **Платівку** в меню програм. Нижче — кожен крок, досвід роботи з Linux не потрібен.

## Що встановить скрипт

| Пакет | Навіщо |
|---|---|
| `mpv` | відтворює звук |
| `kitty` | власне вікно Платівки, яке вміє показувати справжні обкладинки |
| `python3` (+ `python3-venv` на Debian/Ubuntu) | плеєр написано на Python |
| `libnotify` / `notify-send` | сповіщення про трек |

Сам плеєр ставиться в `~/.local/share/plativka` і решту системи не чіпає.

## Крок 1. Завантаження

Відкрийте [останній реліз](https://github.com/dkindratyuk-web/plativka/releases/latest) і завантажте `plativka-…-linux.tar.gz`. Браузер покладе його в теку **Завантаження** (Downloads).

## Крок 2. Відкрийте термінал

- **Ubuntu, Linux Mint, Pop!_OS, Debian (GNOME)**: натисніть **Ctrl + Alt + T**.
- **Fedora (GNOME)**: натисніть клавішу **Super** (з логотипом Windows), наберіть `термінал` або `terminal`, натисніть **Enter**.
- **KDE Plasma** (Kubuntu, Fedora KDE, Manjaro KDE…): відкрийте меню, наберіть `konsole`, натисніть **Enter**.
- **Arch**: ви й так знаєте 🙂

Відкриється вікно з блимаючим курсором. Команди нижче набирайте (або вставляйте сполученням **Ctrl + Shift + V**) у нього, після кожної — **Enter**.

## Крок 3. Розпакуйте й запустіть інсталятор

Скопіюйте ці три рядки по черзі (номер версії в назві може відрізнятися — `*` про це подбає):

```bash
cd ~/Завантаження
tar -xzf plativka-*-linux.tar.gz
cd plativka-*-linux && ./install.sh
```

> Якщо система англійською, тека зветься `Downloads`: тоді перший рядок — `cd ~/Downloads`. Не знаєте назви — наберіть `ls ~` і подивіться.

Скрипт спитає **ваш пароль** — він потрібен, щоб встановити системні пакети. **Під час введення пароля на екрані нічого не з'являється — так і має бути.** Наберіть його й натисніть Enter.

Встановлення триває 1–3 хвилини. Наприкінці ви побачите:

```
✓ Готово! Запуск: знайдіть «Платівка» в меню програм або наберіть plativka у терміналі.
```

## Крок 4. Запустіть Платівку

- Відкрийте меню програм і знайдіть **Платівка** (або **Plativka**). Вона відкриється у власному вікні.
- Або наберіть `plativka` у терміналі (якщо команду не знайдено, спершу відкрийте нове вікно терміналу).

Далі натисніть **L**, щоб додати теку з музикою, — або перетягніть теку з файлового менеджера у вікно Платівки. Див. [Як користуватися](usage.md).

## Що саме робиться на кожній системі

Це знадобиться, лише якщо скрипт не спрацює, — тоді команди можна виконати самостійно.

### Debian / Ubuntu / Linux Mint / Pop!_OS

```bash
sudo apt update
sudo apt install mpv kitty python3 python3-venv libnotify-bin
```

### Fedora

```bash
sudo dnf install mpv kitty python3 libnotify
```

Якщо `mpv` не знаходиться, скрипт спершу підключає вільний репозиторій RPM Fusion:

```bash
sudo dnf install https://mirrors.rpmfusion.org/free/fedora/rpmfusion-free-release-$(rpm -E %fedora).noarch.rpm
sudo dnf install mpv
```

### Arch / Manjaro / EndeavourOS / CachyOS

```bash
sudo pacman -S --needed mpv kitty python libnotify
```

### openSUSE

```bash
sudo zypper install mpv kitty python3 libnotify-tools
```

### Далі — на будь-якій системі

```bash
python3 -m venv ~/.local/share/plativka/venv
~/.local/share/plativka/venv/bin/pip install .      # виконувати в розпакованій теці
```

Скрипт також створює `~/.local/bin/plativka` і пункт меню `~/.local/share/applications/plativka.desktop`.

Пакети вже стоять або не хочете, щоб скрипт їх чіпав? Запустіть `PLATIVKA_SKIP_PACKAGES=1 ./install.sh`.

## Інтеграція з робочим столом

- **Медіаклавіші** (Грати/Пауза, Наступний, Попередній на клавіатурі чи навушниках) працюють самі.
- **Віджет плеєра** в GNOME (верхня панель → сповіщення/календар) і KDE Plasma (системний лоток) показує трек і обкладинку та керує Платівкою. Так само працює `playerctl`.
- Закриття вікна закриває Платівку.

## Оновлення

Завантажте новий архів і знову запустіть із нього `./install.sh`. Медіатека, список і налаштування збережуться.

## Видалення

З розпакованої теки:

```bash
./uninstall.sh          # прибрати плеєр, залишити налаштування й медіатеку
./uninstall.sh --all    # прибрати й налаштування та медіатеку
```

Системні пакети (mpv, kitty) лишаються — ними можуть користуватися інші програми. За бажанням видаліть їх менеджером пакетів.
