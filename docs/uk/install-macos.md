# Встановлення Платівки на macOS

[English](../en/install-macos.md) · [До README](../../README.uk.md)

DMG містить усе потрібне: сам плеєр, звуковий рушій mpv і власне вікно плеєра (на основі kitty), яке вміє показувати справжні обкладинки. Homebrew, Python і програма «Термінал» не потрібні.

## 1. Оберіть потрібний файл

Відкрийте [останній реліз](https://github.com/dkindratyuk-web/plativka/releases/latest) і завантажте один файл:

| Ваш Mac | Файл |
|---|---|
| Apple Silicon (M1, M2, M3, M4…) | `Plativka-…-macos-arm64.dmg` |
| Intel | `Plativka-…-macos-x86_64.dmg` |

Не знаєте, який у вас? Натисніть  у верхньому лівому куті → **Про цей Mac**. Якщо в рядку «Чип» написано *Apple M…* — беріть arm64. Якщо «Процесор … Intel» — x86_64.

Мінімальна macOS: 14 Sonoma для Apple Silicon, 15 Sequoia для Intel (так зібрано вкладений mpv).

## 2. Встановлення

1. Двічі клацніть завантажений `.dmg`. Відкриється вікно з **Plativka** і текою **Applications** (Програми).
2. Перетягніть **Plativka** на **Applications**.
3. Закрийте вікно і вийміть диск «Plativka» в бічній панелі Finder (⏏).

## 3. Перший запуск (лише один раз)

Платівка безкоштовна й не підписана платним сертифікатом розробника Apple, тому macOS блокує перший запуск. Так і має бути — ось як дозволити:

1. Відкрийте **Програми** й двічі клацніть **Plativka**.
2. macOS напише *«Plativka» не відкрито* / *Apple не вдалося перевірити…*. Натисніть **Готово** (не «Перемістити в Смітник»).
3. Відкрийте  → **Системні параметри** → **Конфіденційність і безпека**.
4. Прокрутіть униз до розділу **Безпека**. Біля повідомлення *«Plativka» було заблоковано…* натисніть **Все одно відкрити**.
5. Введіть пароль від Mac або прикладіть палець до Touch ID і ще раз натисніть **Все одно відкрити**.

Далі Платівка відкривається звичайним подвійним кліком. Її можна перетягнути в Dock.

> Для досвідчених: те саме робить команда в Терміналі
> `xattr -dr com.apple.quarantine /Applications/Plativka.app`

## 4. Додайте музику

- Натисніть **L** і оберіть теку (стрілками, Enter — відкрити теку, потім **Додати цю теку**), **або**
- просто перетягніть теку з музикою з Finder у вікно Платівки.

Потім у медіатеці праворуч розгорніть виконавця → альбом і натисніть **Enter** на треку. Решта — в [інструкції з користування](usage.md).

## Оновлення

Завантажте новий DMG і знову перетягніть Plativka в Програми із заміною. Медіатека, список і налаштування збережуться.

## Видалення

Перетягніть **Plativka** з Програм у Смітник. Щоб прибрати й налаштування та кеш медіатеки, видаліть теки `~/.config/plativka` і `~/.cache/plativka` (у Finder: **Перехід → Перейти до теки…**).

## Запуск із командного рядка (за бажанням)

Якщо хочете запускати плеєр у своєму терміналі (Ghostty, iTerm2, Термінал), замість DMG можна встановити консольну версію:

```bash
brew install mpv pipx
pipx install git+https://github.com/dkindratyuk-web/plativka
plativka
```

Стандартний Термінал не вміє показувати картинки, тож обкладинки там складаються з кольорових квадратиків; Ghostty, kitty, iTerm2 і WezTerm показують справжні.
