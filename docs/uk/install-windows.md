# Встановлення Платівки на Windows

[English](../en/install-windows.md) · [До README](../../README.uk.md)

Платівка має дві версії — оберіть одну або встановіть обидві (під час першого запуску віконна Платівка підхоплює теки з музикою і список з консольної). Обидві працюють на Windows 10 і 11 (64-біт), і кожен інсталятор містить усе потрібне, разом зі звуковим рушієм mpv.

| | **Віконна Платівка** (рекомендовано) | **Платівка для термінала** |
|---|---|---|
| Що це | звичайне вікно; фон Mica на Windows 11 | текстовий інтерфейс у класичному вікні консолі |
| Обкладинки | справжні картинки | кольоровими квадратиками |
| Файл | `Plativka-Desktop-…-windows-x64-setup.exe` | `Plativka-…-windows-x64-setup.exe` |
| У меню «Пуск» | **Plativka Desktop** | **Plativka** |

## 1. Завантаження

Відкрийте [останній реліз](https://github.com/dkindratyuk-web/plativka/releases/latest) і завантажте інсталятор потрібної версії.

## 2. Запуск інсталятора

1. Двічі клацніть завантажений файл.
2. Windows може показати синє вікно **«Захист ОС Windows»** (SmartScreen). Так буває з кожною безкоштовною програмою без платного сертифіката. Натисніть **Докладніше**, потім **Усе одно запустити**.
3. Оберіть мову інсталятора, прийміть ліцензію і кілька разів натисніть **Далі**. Можна поставити галочку **Створити ярлик на робочому столі**.
4. Залиште галочку **Запустити Платівку** і натисніть **Завершити**.

Права адміністратора не потрібні: за замовчуванням Платівка встановлюється лише для вашого користувача.

## 3. Додайте музику

- Натисніть **L** (або кнопку **+ Тека** в медіатеці) — відкриється звичайне вікно Windows «Вибір папки». **Або**
- перетягніть теку з музикою з Провідника у вікно Платівки.

Потім розгорніть у медіатеці виконавця → альбом і двічі клацніть трек (або натисніть **Enter**) — увесь альбом потрапить у список. Решта: [як користуватися віконною Платівкою](desktop.md) · [консольною версією](terminal.md).

## Медіаклавіші, панель мультимедіа і сповіщення

В обох версіях ⏮ ⏯ ⏭ на клавіатурі й навушниках керують Платівкою, панель мультимедіа Windows (поруч із віконцем гучності) показує трек з обкладинкою, а сповіщення про трек приходять з обкладинкою (вмикаються й вимикаються клавішею `N`).

## Іконка в треї

Поки Платівка працює, її іконка є в треї біля годинника (якщо не видно — клацніть стрілку **^**).

**Віконна Платівка**: клік по іконці показує вікно; правий клік — **Грати / пауза**, **Наступний трек**, **Попередній трек** і **Вийти з Платівки**. Закриття вікна хрестиком ✕ виходить із програми — якщо не поставити галочку **☰ → Вигляд → Згортати в трей**: тоді ✕ і згортання ховають вікно в трей, а музика грає далі.

**Консольна версія**: правий клік по іконці — **Грати / пауза**, **Наступний / Попередній трек**, **Показати плеєр**, **Платівка на GitHub** і **Вийти з Платівки**. ✕ виходить; **H** ховає вікно в трей (або поставте галочку **Згортати в трей** у меню трею). Ярлик із меню «Пуск» відкриває плеєр у власному класичному вікні консолі — саме це дає змогу ховати його в трей і згортати до міні-плеєра. Якщо запустити його в Windows Terminal, працює все, крім цих двох речей.

## Оновлення

Запустіть новий інсталятор — він замінить стару версію, а медіатека, список і налаштування збережуться. Якщо Платівка запущена, інсталятор спершу сам її закриє (починаючи з версії 1.3.4; зі старішими версіями перед оновленням вийдіть із Платівки через трей).

## Видалення

**Параметри → Програми → Інстальовані програми → Plativka Desktop** (або **Plativka**) **→ Видалити**. Налаштування й кеш медіатеки лишаються в `%APPDATA%\Plativka` і `%LOCALAPPDATA%\Plativka`; видаліть ці теки, якщо хочете прибрати і їх.
