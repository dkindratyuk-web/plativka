# Як користуватися Платівкою

[English](../en/usage.md) · [До README](../../README.uk.md)

## Вікно

Платівка влаштована як Winamp:

- **Головне вікно** (зліва вгорі): обкладинка альбому, великий годинник, індикатор рівня L/R, біжучий рядок із назвою треку, формат (MP3, бітрейт, частота), перемикачі перемішування / повтору / сповіщень, смуга перемотування, кнопки керування й гучність.
- **Список відтворення** (зліва внизу): що гратиме далі. Трек, що грає, позначено ▶.
- **Медіатека** (праворуч): уся музика з доданих тек — за виконавцями → альбомами або за теками.

У вузькому вікні (менше ~100 символів) частини стоять стовпчиком, а **M** перемикає нижню частину між списком і медіатекою.

Мишкою клікається все: кнопки, смуга перемотування (перейти в потрібне місце), годинник (минуло ↔ залишилось), гучність (клік або колесо), перемикачі.

## Як додати музику

Платівка ніколи не копіює й не змінює ваші файли — лише читає їх.

- **L** або кнопка **+ Тека** в медіатеці: оберіть теку стрілками, Enter відкриває теку, **↑ Вище** — на рівень вище, **Додати цю теку** — підтвердити. Шлях можна й надрукувати чи вставити.
- **Перетягування**: перетягніть теку з Finder / Провідника / файлового менеджера у вікно Платівки. Теки потрапляють у медіатеку, окремі аудіофайли — в кінець списку.
- **− Тека** прибирає теку з медіатеки (файли на диску лишаються). Якщо тек дві чи більше, першим у списку стоїть **✕ Прибрати всі теки** — він спорожнює медіатеку після підтвердження. **↻** пересканує медіатеку — після того як ви доклали файли в теку.

Формати: MP3, FLAC, M4A/AAC/ALAC, OGG/Opus, WAV, AIFF, WMA.

Теги читаються з файлів. Файли без тегів розбираються з імені: `01. Виконавець - Назва.mp3` → виконавець *Виконавець*, назва *Назва*. Старі теги в кодуванні Windows-1251 («кракозябри» на кшталт «Ïðèâ³ò») виправляються автоматично.

## Медіатека → список

| У медіатеці | Що станеться |
|---|---|
| **Enter** на треку (або подвійний клік) | у список іде весь альбом/тека, грає цей трек |
| **P** на виконавці, альбомі чи теці | замінити ним список і грати |
| **A** на будь-чому | додати в кінець списку |
| кнопка **▶ Усе** або **Shift+P** | уся медіатека в список (з випадкового треку, якщо ввімкнено перемішування) |

У списку: **Enter** або подвійний клік — грати трек, **Delete** — прибрати, **Очистити** — спорожнити список, **+ Тека** — додати теку одразу в список, не додаючи її в медіатеку.

**J** (або **/**) — швидкий пошук по медіатеці й списку: наберіть кілька літер виконавця, назви чи альбому й натисніть Enter.

## Відтворення

| Клавіша | Дія |
|---|---|
| `Z` `X` `C` `V` `B` | назад · грати · пауза · стоп · далі |
| `Пробіл` | пауза / продовжити |
| `←` `→` | перемотати на 5 секунд |
| `+` `−` | гучність |
| `S` | перемішування увімк/вимк |
| `R` | повтор: вимк → усе → один |

Наприкінці списку Платівка зупиняється й пише про це. Щоб грало по колу, увімкніть **повтор: все**.

«Назад» повертає на початок поточного треку, якщо зіграно більше 3 секунд, інакше — на попередній трек (у режимі перемішування — на той, що справді грав перед цим).

## Обкладинки й кольори

- Колір рамок і годинника береться з обкладинки альбому, що грає.
- **O** перемикає: звичайна обкладинка → велика (потрібне вікно від 30 рядків заввишки) → обкладинки вимкнено. Тоді на їхньому місці малюється платівка, що крутиться під час гри.
- Обкладинки беруться з самих файлів або з `cover.jpg` / `folder.jpg` / `front.jpg` поруч.
- **Kitty, Ghostty, iTerm2, WezTerm** і нові версії **Windows Terminal** показують справжні картинки. Інші термінали (Термінал macOS, класична консоль Windows, GNOME Terminal…) малюють обкладинки кольоровими квадратиками. DMG для macOS і скрипт для Linux відкривають Платівку у власному вікні kitty, тож там обкладинки справжні.
- Якщо обкладинка порожня, запустіть `plativka --no-images`.

## Сповіщення про трек

**N** перемикає: **сповіщ: плеєр** (віконце всередині плеєра) → **сповіщ: macOS / Windows / Linux** (системне сповіщення, видно навіть коли плеєр у фоні) → **сповіщ: вимк**.

На macOS перше системне сповіщення може попросити дозвіл для «Редактор скриптів» — це системний компонент, який його показує.

## Інтеграція з системою

- **Windows — іконка в треї**: грати/пауза, наступний, попередній, показати плеєр, вийти. **H** ховає вікно в трей; пункт **Згортати в трей** у меню трею робить те саме при згортанні вікна. Закриття хрестиком ✕ — вихід.
- **Linux — MPRIS**: медіаклавіші, віджет плеєра GNOME/KDE і `playerctl` керують Платівкою й показують трек та обкладинку.
- **macOS — медіаклавіші** на клавіатурі й навушниках зазвичай працюють, поки Платівка грає.

## Теми й мова

- **T** — світла / темна тема.
- **F2** — мова інтерфейсу (українська ↔ англійська), застосовується після перезапуску. За замовчуванням — мова системи. Також можна запустити з `plativka --lang=uk` чи `--lang=en`.

## Де Платівка зберігає дані

| | Налаштування, список | Кеш медіатеки, журнали |
|---|---|---|
| macOS, Linux | `~/.config/plativka/config.json` | `~/.cache/plativka/` |
| Windows | `%APPDATA%\Plativka\config.json` | `%LOCALAPPDATA%\Plativka\cache\` |

Список, позиція в поточному треку, гучність, тема й усі перемикачі зберігаються самі.

## Параметри запуску

| Параметр | Що робить |
|---|---|
| `--demo` | без звуку й без mpv — просто роздивитися |
| `--lang=uk`, `--lang=en` | мова інтерфейсу |
| `--no-images` | обкладинки квадратиками, навіть якщо термінал уміє картинки |
| `--256`, `--truecolor` | примусово 256 кольорів або 24-бітний колір |
